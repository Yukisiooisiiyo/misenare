## 1. 競合マップ（全体像）

```
                   誰が書くか
   本部が作って配る  ←───────────────────→  現場が書ける
        │                                        │
  Teachme Biz                               Kibela / NotePM
  ClipLine(ABILI)                           esa / DocBase / Qast
  tebiki / shouin+                          Notion / Confluence
  Shopらん / 店舗matic                            │
  STORE+ / 店番長                                 │
        │                                        │
  ──────┼────────────────────────────────────────┼──────
        │                                        │
   店舗/拠点課金が主流                      ユーザー課金が主流
   店舗横断の全文検索は弱い                 店舗オペレーション文脈が無い
```

ミセナレが狙っているのは、この図の **左下（店舗課金・店舗文脈）と右上（現場が書ける・全文検索）の交点** です。この交点に正面から座っている製品は、今回の調査では見つかりませんでした。ただし**近傍は混んでいます**（§3、§6参照）。

## 5. 問3への回答：「現場のアルバイト・パートが書いて、承認を経て、店舗横断で全文検索できる」ツールは実在するか

### 5-1. 結論

**「その組み合わせを、店舗オペレーション向けに、店舗課金で提供している製品」は、今回の調査では見つかりませんでした。**
**ただし、個々の要素はほぼ全て既存製品が持っており、組み合わせの近傍は相当に混んでいます。**

- **販路と置換コストの壁**: Shopらん／店舗maticが**本部・店舗間コミュニケーションツール市場でシェア51.6%、約63,000店**を押さえています。家電量販店の本部が既にこの手のツールを入れている確率は低くなく、ミセナレは「置き換え」ではなく「併設」を提案することになります。併設は本部の決裁が通りにくい最大の障壁です。

## 8. 申請書を書くときの推奨スタンス（調査者の所見）

1. **個別機能の新規性を主張しない。** 「0件検索の可視化が独自」と書くと、Guru・Zendeskを知る審査員には即座に崩されます。「海外のナレッジ基盤では標準だが、日本の店舗向けSaaSには存在しない」という**移植のフレーム**で書くほうが安全かつ正確です。
2. **価格モデルの独自性も主張しない。** 店番長4,800円/店、STORE+3,000円/店が既にあります。主張すべきは価格ではなく**「閲覧ID無制限」と「LLMを使わないコスト構造」の因果**です。
3. **主張の中心は「組み合わせ」と「セグメント」に置く。** 「店舗横断の全文検索を持つ店舗向けツールが存在しない」という§6-2-1の事実が、最も検証に耐える差別化要因です。
4. **競合として最も危険なのはKibelaとNotePM**（現場が書ける＋承認＋全文検索＋同義語を既に持つ）であり、Shopらん等ではありません。申請書の競合表にこの2つを入れていないと、「調べていない」と見なされます。入れたうえで「店舗オペレーション文脈と店舗課金がない」と差分を明示するのが正攻法です。
5. **家電量販店の店舗数は約3,400〜3,500店（主要11社）** です。1店舗4,800円×12ヶ月で計算すると、**日本の家電量販店を100%取っても年商約2億円**。TAMとしては小さいので、**「家電量販店を起点に、同じ構造を持つ多店舗小売（ドラッグストア・ホームセンター等）へ展開する」という拡張シナリオを必ず併記してください。** ここを書かないと「市場性・成長性」で落ちます。
